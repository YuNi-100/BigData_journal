# 서울에서 5억으로 아파트를 살 수 있을까?

2025년 서울 아파트 실거래로 살펴보는 5억 이하 주택의 지역·면적·시기별 특징.

## 데이터와 분석 기준

- 출처: 서울열린데이터광장 「서울시 부동산 실거래가 정보」
- URL: https://data.seoul.go.kr/dataList/OA-21275/S/1/datasetView.do
- 수집일: 2026년 11월 5일. 공식 CSV 내려받기의 계약일 필터에 2025를 입력해 확보.
- 원본 135,242행에서 계약일이 2025년이고, 건물용도가 아파트이며, 취소일과 권리구분이 비어 있고, 거래금액이 양수인 행만 사용.
- 접수연도가 2026년이어도 계약일이 2025년이면 포함. 취소·분양권·입주권 제외.
- 분석 대상 75,129건, 5억 이하 8,017건(10.67%). 5억 원은 원본 단위로 50,000만 원이며 경계값을 포함.
- CSV는 UTF-8 BOM 인코딩. 요약표의 비중은 퍼센트 숫자(10.67)이며 0.1067 형태가 아님.
- 이는 거래 건수이지 고유한 집의 개수나 현재 매물 수가 아님. 면적·연식·거래방식 차이가 있으므로 지역 차이를 입지의 효과로 단정하지 않음. 취득세·중개보수 등 부대비용은 포함하지 않음.

## 과제 1: 그래프 3개

1. 선그래프: 월별 5억 이하 아파트 거래 비중. 가로축 계약월, 세로축 비중(%). 월별 요약 CSV 사용.
2. 막대그래프: 자치구별 5억 이하 아파트 거래 건수. 내림차순 정렬, 건수 축은 0부터 시작. 자치구별 요약 CSV 사용. 전체 거래가 많은 지역일 수 있으므로 비중도 함께 확인.
3. 히스토그램: 서울 아파트 전체 거래가격 분포. 분석용 CSV의 거래금액_억원을 1억 원 간격으로 묶고 거래 행 수를 집계. 가격 구간은 연속으로 표시하고 전체 범위를 포함. 고가 거래를 임의로 삭제하거나 축을 생략하지 않음.

각 그래프에 제목, 단위, 출처, 분석 기간 및 제외 기준을 표시. 출처 표기 예: 서울열린데이터광장, 서울시 부동산 실거래가 정보 / 2025년 계약, 취소·분양권·입주권 제외 / 2026.11.05 수집.

## 과제 2: Power BI 대시보드

- 불러올 파일: 서울아파트_2025_분석용.csv. 요약 파일을 연결할 필요 없이 이 파일 하나로 제작 가능.
- 표 이름을 '거래'로 변경. 계약일은 날짜, 거래금액과 면적은 숫자, 오억이하는 정수로 설정.
- 카드: 전체거래, 오억이하거래, 오억이하비중.
- 차트: 월별 5억 이하 비중 선그래프, 자치구별 5억 이하 거래 건수 막대그래프.
- 슬라이서: 자치구, 면적_m2. 5억 이하 여부를 전체 페이지 필터로 설정하면 분모까지 줄어들므로 사용하지 않음.
- 필터 전 전체 화면과 필터 후 특정 자치구 화면을 각각 캡처. 두 화면에 적용 조건을 명시.

측정값은 아래 세 개를 각각 추가:

```dax
전체거래 = COUNTROWS('거래')
```

```dax
오억이하거래 = CALCULATE(COUNTROWS('거래'), '거래'[오억이하] = 1)
```

```dax
오억이하비중 = DIVIDE([오억이하거래], [전체거래], 0)
```

마지막 측정값은 백분율 형식으로 표시. 필터를 적용하면 세 측정값이 같은 지역·면적 조건 안에서 계산됨.

## 전체 화면에서 사용할 이야기 3문장

1. 2025년 서울 아파트 매매 거래 75,129건 가운데 5억 원 이하 거래는 8,017건으로 10.67%를 차지했다.
2. 5억 원 이하 거래 건수가 가장 많은 자치구는 노원구로 1,790건이었으며, 노원구 전체 거래의 33.16%였다.
3. 도봉구는 5억 원 이하 거래가 784건으로 노원구보다 적었지만, 구 전체 거래에서 차지하는 비중은 44.65%로 더 높았다.

필터 후 이야기에는 해당 화면에서 새로 계산된 숫자를 사용. 전체 화면의 숫자를 그대로 복사하지 않음.
